NEXT STEPS
===========

To start using Docker:

1. Build the image (first time):
   $ docker-compose build

2. Start the container:
   $ docker-compose up -d

3. Access the app:
   $ open http://localhost:8501
   (or visit http://localhost:8501 in browser)

4. View logs:
   $ docker-compose logs -f erp

5. Stop the container:
   $ docker-compose down
